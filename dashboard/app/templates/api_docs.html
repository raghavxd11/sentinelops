JSON over HTTP. Base URL {{ base_url }}. The GET responses below are live data from this database.

POST/api/deployments X-API-Token required

Jenkins calls this at the end of every pipeline run. The token must equal the API_TOKEN environment variable and is compared in constant time. A status of FAILED or ROLLED_BACK opens an incident linked to the deployment.

Body fields
servicerequiredName of a service on the Services page
commit_hashrequiredFull git commit SHA
statusrequiredSUCCESS, FAILED, ROLLED_BACK or IN_PROGRESS
commit_author, commit_message, branchoptionalShown in the trace
build_number, duration_secondsoptionalIntegers
image_tagoptionalDefaults to the short commit SHA
failed_stageoptionalCheckout, Test, Build, Scan, Push, Deploy or Health check
committed_atoptionalISO 8601 commit time, used for lead time
Request
curl -X POST {{ base_url }}/api/deployments \
  -H "X-API-Token: $API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "service": "demo-app",
    "commit_hash": "7c1e4b9d2f0a8e6b5c3d1f4a9b8e7d6c5b4a3f21",
    "commit_author": "Raghav Pandey",
    "commit_message": "feat: read greeting from GREETING env var",
    "branch": "main",
    "build_number": 48,
    "image_tag": "7c1e4b9",
    "status": "ROLLED_BACK",
    "duration_seconds": 162,
    "committed_at": "2026-11-13T14:01:52+05:30"
  }'
Response 201 Created (200 when it completes a build reported earlier as IN_PROGRESS)
{
  "id": 51,
  "service": "demo-app",
  "status": "ROLLED_BACK",
  "incident_id": 12,
  ...
}
Errors
400Missing field, unknown status, or body is not JSON
401Missing or wrong X-API-Token
404Service name is not registered

curl {{ base_url }}/api/stats

GET/health

Liveness check used by the Docker HEALTHCHECK. Runs SELECT 1 against the database and returns 503 if it does not answer.

Request
curl {{ base_url }}/health
Response 200 OK
{
  "database": "ok",
  "status": "ok"
}
