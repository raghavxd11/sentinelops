Pipeline stages

checkout lint + test + scan build image scan push to ECR deploy health check
pass tag latest-stable report SUCCESS
fail roll back to latest-stable report ROLLED_BACK open incident

How it works

  1. Every push runs the pipeline. Jenkins lints, tests and scans the code, then builds an image tagged with the commit SHA.
  2. Trivy gates the build. A HIGH or CRITICAL finding with a fix available stops the image before it is pushed.
  3. Deploys are health-checked. If /health fails 5 times, the last stable image is redeployed automatically.
  4. Every deployment is recorded here. Commit, author, build number, image tag, status and duration, with an incident opened for each failure.

Stack

Git · Jenkins · Docker · Trivy · Terraform · AWS (EC2, ECR, CloudWatch, SNS)
